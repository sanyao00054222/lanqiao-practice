# 蓝桥杯赛刷题记录
1.回文数平方和数（huiwenshu.cpp）
题目：若一个正整数本身是回文数（十进制正读反读相同，且不以 0 开头），且把它各个数位上的数字平方后再求和，得到的结果也是一个完全平方数，则称它为“回文平方和数”。例如 1 是回文数，1²=1=1²，所以是；121 是回文数，但 1²+2²+1²=6 不是完全平方数，所以不是。请问在 1 到 2026（含）之间，一共有多少个回文平方和数？
思路：利用两个bool类型函数分别判断数字是否为回文数，是否为完全平方数->在主函数中利用if判定，若都符合则计数。
判断回文数方法：转换一半(判断转换后的数字是否比原本数字大)
# 出错点：在编写代码过程中没考虑到数字小于0，以及末尾为0的情况（代码第5行）对于判断完全平方数的临时值设定不理解。
